# Music Explorer

Вебзастосунок для пошуку музики, відкриття нових виконавців і створення персональних плейлистів. Інтерфейс побудований на React 19, TypeScript, Vite та Tailwind CSS v4.

## Предметна область

Music Explorer працює з каталогом треків і виконавців Audius. Можна переглядати каталог, сторінки треків і артистів, зберігати обране та керувати власними плейлистами.

## Локальний запуск

Потрібен Node.js 22 або новіший.

```bash
npm ci
npm run dev
```

Для перевірок і production-збірки:

```bash
npm run lint
npm run build
npm run preview
```

## GitHub Pages

Після публікації застосунок буде доступний за адресою `https://kiogo2805.github.io/music-explorer/#/tracks`. Workflow у `.github/workflows/deploy.yml` перевіряє та збирає застосунок на кожен push до `main`, а потім публікує `dist` у GitHub Pages. У налаштуваннях репозиторію потрібно вибрати GitHub Actions як джерело Pages.

## Архітектура feature-first

Код згрупований за призначенням: `app` містить провайдери, маршрути й layout; `pages` — сторінки маршрутів; `features` — користувацькі сценарії; `entities` — доменні моделі; `shared` — спільні компоненти, конфігурація, API та утиліти. Такий поділ дозволяє розвивати функції незалежно, не змішуючи UI, доменні дані та інтеграції.

## Керування станом

TanStack Query відповідає за server state: завантаження треків/артистів, кешування та повторні запити. Zustand із persist middleware зберігає в `localStorage` обрані треки, плейлисти, вибраний трек, гучність і стан вимкнення звуку. Прапорець відтворення (`isPlaying`) не зберігається між перезавантаженнями сторінки.
